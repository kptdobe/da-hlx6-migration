About sign-in and permissions

Saved sessions are restored automatically when usable; no browser opens for this check. DA uses the helper's local token cache. AWS validates saved credentials and can refresh them while the saved login session remains valid. Its overall session deadline is not provided. DA tokens cannot refresh silently during a run.

Sign-in buttons explicitly open a fresh browser login. Finish there and return here. For AWS, select your KLAM operator console session; sign into KLAM first if needed. AWS CLI 2.32+ and local-development sign-in permission are required. Site and storage permissions are checked during analysis. Read-only R2 credentials must be configured on the local server.
